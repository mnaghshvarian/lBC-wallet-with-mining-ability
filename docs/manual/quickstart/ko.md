# LBC Wallet — 빠른 시작 가이드

LBC Wallet은 Windows, Mac, Linux, Android에서 쓸 수 있는 **LBRY Credits(LBC)** 무료 지갑 앱이에요. LBC를 보관하고, 보내고, 받고, 채굴할 수 있어요. 그림이 포함된 전체 설명서(영어)는 여기에서 볼 수 있어요: [docs/manual](../README.md).

> **경고:** LBC Wallet은 실험 단계의 소프트웨어이며 **보안 감사를 받지 않았습니다**. 자금 손실로 이어지는 오류가 있을 수 있습니다. **사용에 따른 모든 위험은 본인이 부담합니다**. 저작자는 어떠한 손실에도 책임지지 않습니다. 처음에는 소액으로 시작하세요. 전문: [DISCLAIMER](../../../DISCLAIMER.md).

## 1. 다운로드

반드시 공식 페이지에서만 다운로드하세요:
**<https://github.com/mnaghshvarian/lBC-wallet-with-mining-ability/releases/latest>**
(아래로 스크롤해서 **Assets**를 찾으세요).

| 기기 | 파일 |
| --- | --- |
| Windows | `LBC-Wallet-Setup-x64.exe` |
| Apple 칩 탑재 Mac(M1, M2…) | `LBC-Wallet-mac-arm64.dmg` |
| Intel 칩 탑재 Mac | `LBC-Wallet-mac-x64.dmg` |
| Ubuntu, Debian, Mint | `lbc-wallet_amd64.deb` |
| Fedora, openSUSE | `lbc-wallet.x86_64.rpm` |
| 그 밖의 Linux | `LBC-Wallet-linux-x86_64.AppImage` |
| Android 7 이상 | `LBC-Wallet-android.apk` |

## 2. 설치

* **Windows:** 파일을 더블클릭하세요. “Windows의 PC 보호” 창이 나타나면 **추가 정보 → 실행**을 클릭하세요. 라이선스에 동의한 다음 **설치**를 클릭하세요.
* **Mac:** `.dmg` 파일을 열고 **Agree**(동의)를 클릭한 다음, **LBC Wallet**을 **Applications**(응용 프로그램) 폴더로 끌어다 놓으세요. 처음 열 때는 macOS가 앱을 차단해요. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래로 스크롤한 다음 **그래도 열기**를 클릭하세요.
* **Linux:** `.deb` 또는 `.rpm` 파일을 더블클릭하면 소프트웨어 센터에서 설치할 수 있어요. 또는 AppImage 파일을 실행 가능하게 만든 다음(마우스 오른쪽 버튼 클릭 → 속성 → 권한 → *파일을 프로그램으로 실행 허용*) 더블클릭하세요.
* **Android:** 휴대전화에서 APK 링크를 열고 **무시하고 다운로드**를 누른 다음 **열기**를 누르세요. 안내가 나오면 사용하는 브라우저에 “**출처를 알 수 없는 앱 설치**”를 허용하고 **설치**를 누르세요. Play Protect 경고가 나오면 **세부정보 더보기 → 무시하고 설치하기**를 누르세요.

## 3. 처음 시작하기

면책 조항을 읽고 체크박스 3개에 모두 체크한 다음 **동의하고 계속하기**를 클릭하세요. 언어는 지구본 버튼으로 선택할 수 있어요.

## 4. 지갑 만들기 또는 복원하기

* **새로 만들려면:** **새 지갑 만들기**를 클릭하고 이름과 비밀번호를 정한 다음, **복구 문구 12단어를 순서대로 종이에 적어 두세요**. 앱이 그중 3개를 확인해요.
* **이미 복구 문구가 있다면**(이 앱, LBRY Desktop, Odysee 또는 다른 BIP39 지갑의 문구): **복구 문구로 복원**을 클릭하고 단어를 입력하세요.

**복구 문구가 곧 내 돈이에요.** 이 단어를 가진 사람은 누구나 내 LBC를 가져갈 수 있어요. 절대 다른 사람에게 알려 주지 말고, 웹사이트에 입력하지 말고, 사진으로 저장하지 마세요. 프로젝트 관계자가 복구 문구를 묻는 일은 절대 없어요.

## 5. 받기

**받기**를 클릭하세요. 주소(`b`로 시작해요)를 복사하거나, 보내는 사람에게 QR 코드를 보여 주세요.

## 6. 보내기

**보내기**를 클릭하고 주소를 붙여넣은 다음 금액을 입력하고 **검토**를 클릭하세요. 모든 내용을 확인한 뒤 비밀번호를 입력하고 **보내기**를 클릭하세요. 보낸 돈은 되돌릴 수 없어요.

## 7. 채굴하기

**채굴** → **채굴 시작**을 클릭하세요(Android에서는 **더보기 → 채굴**). 기본값은 LBRYPool 채굴 풀이에요. 이 풀에서 10 LBC를 벌면 지갑으로 자동 지급돼요. 일반 컴퓨터로는 버는 양이 아주 적고 전기도 많이 써요. 원하면 **배터리 사용 시 일시 중지**와 **유휴 시에만**을 켜 두세요. 휴대전화로는 버는 양이 더 적어요. LBC Wallet이 화면에 열려 있고 휴대전화가 충전 중일 때만 채굴하며, 배터리 온도가 올라가면 일시 중지돼요.

## 8. 내 노드 실행하기(선택 사항, 컴퓨터 전용)

**노드**를 클릭하고 여유 공간이 약 **150 GB** 있는 폴더를 고른 다음(**변경…**), **노드 시작**을 클릭하세요. 처음 다운로드하는 데 1~3일이 걸려요. 진행률이 100%가 되면 지갑이 내 노드를 사용하고, **솔로 (풀 노드)** 모드로 채굴할 수도 있어요.

## 9. LBC와 비트코인 교환하기(선택 사항)

**스왑**에서는 거래소를 거치지 않고 다른 사람과 직접 LBC와 비트코인을 교환할 수 있어요. 두 사람 모두 상대방의 코인을 받거나, 두 사람 모두 자기 코인을 돌려받거나 둘 중 하나예요. 한 사람이 **스왑 시작**을 클릭해 초대 코드를 보내고, 다른 사람이 **코드로 참여**를 클릭해요. 스왑이 **완료**로 표시될 때까지 앱을 열어 두세요. 스왑은 새로운 기능이니 소액으로 시작하세요. 자세한 내용: [설명서 21장](../README.md#21-buy-sell-or-swap-lbc).
