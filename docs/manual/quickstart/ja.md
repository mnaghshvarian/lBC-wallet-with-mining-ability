# LBC Wallet — クイックスタート

LBC Wallet は、Windows、Mac、Linux、Android で **LBRY Credits（LBC）** の保管・送金・受け取り・マイニングができる無料アプリです。画像付きの完全版マニュアル（英語）は [docs/manual](../README.md) にあります。

> **警告**：LBC Wallet は実験的なソフトウェアで、**監査を受けていません**。資金を失う原因となる不具合が含まれている可能性があります。**ご利用はすべて自己責任となります**。作者はいかなる損失についても責任を負いません。まずは少額から始めてください。全文は [DISCLAIMER](../../../DISCLAIMER.md) をご覧ください。

## 1. ダウンロード

ダウンロードは必ず公式ページから行ってください：
**<https://github.com/mnaghshvarian/lBC-wallet-with-mining-ability/releases/latest>**
（下にスクロールすると **Assets** があります）。

| デバイス | ファイル |
| --- | --- |
| Windows | `LBC-Wallet-Setup-x64.exe` |
| Apple チップ搭載の Mac（M1、M2…） | `LBC-Wallet-mac-arm64.dmg` |
| Intel チップ搭載の Mac | `LBC-Wallet-mac-x64.dmg` |
| Ubuntu、Debian、Mint | `lbc-wallet_amd64.deb` |
| Fedora、openSUSE | `lbc-wallet.x86_64.rpm` |
| その他の Linux | `LBC-Wallet-linux-x86_64.AppImage` |
| Android 7 以降 | `LBC-Wallet-android.apk` |

## 2. インストール

* **Windows**：ファイルをダブルクリックします。「Windows によって PC が保護されました」と表示されたら、**詳細情報 → 実行**をクリックします。ライセンスに同意して、**インストール**をクリックします。
* **Mac**：`.dmg` を開いて **Agree**（同意する）をクリックし、**LBC Wallet** を **Applications**（アプリケーション）フォルダーにドラッグします。初めて開くときは macOS にブロックされるので、**システム設定 → プライバシーとセキュリティ**を開き、下にスクロールして**このまま開く**をクリックします。
* **Linux**：`.deb` または `.rpm` をダブルクリックすると、ソフトウェアセンターでインストールできます。または、AppImage を実行可能にしてから（右クリック → プロパティ → アクセス権 → *プログラムとして実行可能*）、ダブルクリックします。
* **Android**：スマートフォンで APK のリンクを開き、**ダウンロードを続行**をタップしてから**開く**をタップします。求められたら、ブラウザに「**不明なアプリのインストール**」を許可して、**インストール**をタップします。Play Protect の警告が出たら、**詳細 → インストールする**（More details → Install anyway）をタップします。

## 3. 初回起動

免責事項を読み、3つのチェックボックスすべてにチェックを入れて、**同意して続ける**をクリックします。言語は地球儀のボタンで選べます。

## 4. ウォレットの作成または復元

* **新しく作る場合**：**新しいウォレットを作成**をクリックし、名前とパスワードを決めたら、**リカバリーフレーズの12個の単語を順番どおりに紙に書き留めます**。あとでアプリがそのうち3つを確認します。
* **フレーズをすでにお持ちの場合**（このアプリ、LBRY Desktop、Odysee、その他の BIP39 ウォレットで作成したもの）：**リカバリーフレーズから復元**をクリックして、単語を入力します。

**リカバリーフレーズは、あなたのお金そのものです**。これを知っている人は誰でも、あなたの LBC を持ち出せます。絶対に人に教えたり、ウェブサイトに入力したり、写真で保存したりしないでください。このプロジェクトの関係者がフレーズを尋ねることは決してありません。

## 5. 受け取る

**受取**をクリックします。アドレス（`b` で始まります）をコピーするか、送金してくれる相手に QR コードを見せます。

## 6. 送金する

**送金**をクリックし、アドレスを貼り付けて金額を入力したら、**内容を確認**をクリックします。すべて確認してからパスワードを入力し、**送金**をクリックします。送金は取り消せません。

## 7. マイニング

**マイニング** → **マイニング開始**をクリックします（Android では**その他 → マイニング**）。初期設定では LBRYPool というプールを使い、そこで 10 LBC 貯まると自動的にウォレットへ支払われます。一般的なパソコンで得られる報酬はごくわずかで、電気代もかかります。必要に応じて**バッテリー駆動時は一時停止**や**アイドル時のみ**をオンにしてください。スマートフォンで得られる報酬はさらに少なく、マイニングは LBC Wallet が画面に表示されていて充電中のときだけ行われます。バッテリーの温度が上がると一時停止します。

## 8. 自分のノードを動かす（任意・パソコンのみ）

**ノード**をクリックし、空き容量が約 **150 GB** あるフォルダーを選び（**変更…**）、**ノードを起動**をクリックします。最初のダウンロードには1〜3日かかります。進行状況が 100% になると、ウォレットが自分のノードを使うようになり、「**ソロ（フルノード）**」でのマイニングもできるようになります。

## 9. LBC とビットコインを交換する（任意）

**スワップ**を使うと、取引所を通さずに、ほかの人と直接 LBC とビットコインを交換できます。結果は、双方が相手のコインを受け取るか、双方のコインが戻ってくるかのどちらかです。どちらか一方が**スワップを開始**をクリックして招待コードを送り、もう一方が**招待コードで参加**をクリックします。スワップに**完了**と表示されるまで、アプリを開いたままにしてください。スワップは新しい機能なので、まずは少額から始めてください。詳しくは[マニュアルのセクション 21](../README.md#21-buy-sell-or-swap-lbc)をご覧ください。
